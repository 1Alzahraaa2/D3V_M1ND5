# D3V_M1ND5
AI-POWERD mental health support application
# D3V_M1ND5 (Dev Minds) is a mental state monitoring application enhanced with AI. It analyzes users' emotions and mental states and detects signs of depression. It provides personalized mental health advice to raise users' awareness, along with daily tasks considering the user's mood. 

## Problem Statement
Many people are not aware that they may be experiencing depression because they often think it is only temporary sadness. As a result, they may ignore the signs and feel confused, emotionally overwhelmed, or mentally distracted.

## Our Solution
The application analyzes users’ moods and emotions through behavior and voice recognition, then provides personalized guidance to help them take better actions for their mental health. It also suggests simple daily tasks based on the user’s emotional state and helps them improve their well-being.


## Project Goals
- Raising awareness about mental state and depression signs  
- Support users who may be experiencing depression  
- Guide the user to the right action

## System Features (From Code Implementation)

### AI Chat System
The application maintains conversation history to provide contextual AI responses.

### Image Processing
The system analyzes uploaded images using captioning and emotion detection.

### Notification System
The application generates and schedules personalized notifications based on AI output.

### Multithreading
AI processing and image analysis run in the background to keep the UI responsive.

### RTL Support
The interface supports Arabic right-to-left text rendering.

### Real-time UI Updates
The system uses Tkinter event loop (window.after) for smooth updates.

## Challenges
- The AI may analyze emotions from text or voice, but user feelings are not always clearly expressed.  
- The application may sometimes provide general or inappropriate guidance if the model is not well controlled.  
- The system must be carefully designed to avoid causing stress or using harsh or negative language.
